# drifty

Context-aware AI time tracker for Mac.

drifty helps you understand where your day actually went by classifying your laptop activity into Focus, Drift, Learning, and Communication.

Website: [https://drifty.so](https://drifty.so)

## About this repository

This repository is used for public releases, changelogs, and issue tracking for the drifty Mac app.

The application source code is not public at the moment.
